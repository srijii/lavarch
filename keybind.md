# Keybindings

Main modifier: `SUPER` (Windows key).

## Application & window actions

| Keybind | Action |
|---|---|
| `SUPER + Q` | Open terminal (`kitty`) |
| `SUPER + C` | Close active window |
| `SUPER + E` | Open file manager (`dolphin`) |
| `SUPER + R` | Application launcher (`rofi -show drun`) |
| `SUPER + B` | Open browser (`firefox`) |
| `SUPER + SHIFT + V` | Toggle floating |
| `SUPER + SHIFT + S` | Screenshot region to clipboard (`hyprshot`) |
| `Print` | Screenshot region (`hyprshot`) |
| `SUPER + V` | Clipboard history |
| `SUPER + SHIFT + W` | Wallpaper picker |
| `SUPER + Tab` | Cycle focus and bring active to top |

## Mouse bindings

| Keybind | Action |
|---|---|
| `SUPER + mouse:272` | Move window |
| `SUPER + mouse:273` | Resize window |
| `SUPER + mouse_down` | Next workspace |
| `SUPER + mouse_up` | Previous workspace |

## Resize active window

| Keybind | Action |
|---|---|
| `SUPER + SHIFT + Right` | Resize +30px width |
| `SUPER + SHIFT + Left` | Resize -30px width |
| `SUPER + SHIFT + Up` | Resize -30px height |
| `SUPER + SHIFT + Down` | Resize +30px height |

## Media and brightness

| Keybind | Action |
|---|---|
| `XF86AudioRaiseVolume` | Volume +5% |
| `XF86AudioLowerVolume` | Volume -5% |
| `XF86AudioMute` | Toggle mute |
| `XF86AudioMicMute` | Toggle mic mute |
| `XF86MonBrightnessUp` | Brightness +10% |
| `XF86MonBrightnessDown` | Brightness -10% |
| `XF86AudioNext` | Next track |
| `XF86AudioPause` | Play/Pause |
| `XF86AudioPlay` | Play/Pause |
